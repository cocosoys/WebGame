### input-agent 协议（反编译 WebGameInputAgent.class，非 WS 帧）

```
TCP 帧 = 类型(1字节, 1-9) + 参数（Java DataInputStream，**大端**！Python 端须 struct.pack(">BIB")）
 1 键盘:    int LWJGL键码 + byte pressed       例: [1, 17, 1] = KeyW down（W=17 T=45 F5=87 E=18 Space=57）
 2 鼠标移动: int dx + int dy
 3 鼠标按钮: int button + byte pressed
 4 滚轮:    int delta
 5 点击:    int x + int y + int button + byte pressed
 6 GUI 直驱-打开聊天框（displayGuiScreen(new GuiChat)）       ← #7 新增
 7 诊断: 打印 GameSettings int 字段                          ← #7 新增
 8 GUI 直驱-切换视角（GameSettings.thirdPersonView 0→1→2）   ← #7 新增
 9 GUI 直驱-关闭 GUI（displayGuiScreen(null)）                ← #7 新增
```
探测脚本：`WebGame\tools\agent_key_probe.py <port> <lwjgl_code> [hold_sec]`（大端 >BIB，已验证）
GUI 命令脚本：`WebGame\tools\gui_cmd.py <port> <6|7|8|9>`
> 注意 `WebGame\tools\cloud_input_probe.py` 是错误协议（WS 帧格式），会被 agent 丢弃，勿复用。

## 5.5 F5/T 修复记录（#7，2026-10-10，提交 be77ac0）

**根因链**（逐层排除）：
1. 探测脚本用 `struct.pack("<BIB")` 小端，agent 是 Java DataInputStream 大端 → 键码错乱（45→754974720），keyDownBuffer 越界丢弃；**此前"W 移动生效"系误判**（画面变化是自然现象）。
2. `Class.forName("net.minecraft...")` 默认加载器找不到 → 必须 TCCL（LaunchClassLoader）。
3. 运行时方法名是 **SRG 名**（func_74507_a=onTick、func_74510_a=setKeyBindState），MCP 名不存在 → 按参数签名匹配。
4. **最终根因**：MC 窗口失焦（Edge 全屏遮挡）→ `inGameHasFocus=false` → runTick 输入处理段跳过 → `isPressed()` 消费（F5/T 的事件路径）不执行；`Display.isActive()`/`Mouse.isGrabbed()` ASM hook 强制 true 仍不足以恢复。

**方案：GUI 直驱**（绕开按键消费段）：
- 聊天框：反射 `Minecraft.getMinecraft().displayGuiScreen(new GuiChat())`（func_147108_a）
- 视角：直接改 `GameSettings.thirdPersonView`（SRG 字段 field_74320_O）(v+1)%3
- 命令由连接线程写入 `guiPendingCmd`，**MC 主线程 postPollKeyboard 消费**（保证 TCCL=LaunchClassLoader）
- 关键坑：GUI 命令消费必须在 `PENDING_KEYS.isEmpty()` 提前 return **之前**

**验证**：聊天框开（currentScreen=GuiChat+画面准星消失）/关（guiCloseGui invoked）；视角 0→1→2（view toggled 日志+准星隐/现）。
